# 楽譜メモ消しPDF

楽譜の写真から手書きメモ（鉛筆・色ペン）を消して、複数ページを1つのPDFにまとめる
Webアプリです。**端末内で処理が完結**し、写真はどこにも送信されません。
AI・サーバー・課金は不要です。

## ファイル構成
- `index.html` … 画面
- `style.css` … 見た目
- `app.js` … 画像処理（メモ除去）とPDF生成
- `PROJECT.md` / `STATUS.md` / `DECISIONS.md` / `CHANGELOG.md` … 開発ドキュメント

## 使い方
1. ページを開く
2. 「① 写真を選ぶ」で楽譜の写真を選択（複数可。選んだ順にページになる）
3. 自動でメモが除去され、ページのサムネイルが表示される
4. 消え具合が気になれば「② 消し具合の調整」スライダーを動かして「この設定で再処理」
   - 音符が欠ける → 左（メモを残す側）へ
   - メモが残る → 右（メモを消す側）へ
5. 「③ PDFを作成して保存」→ 共有メニューから「ファイル」などに保存

## iPhone（Safari）で使うには
このアプリは「URLで開くWebページまたはローカルHTMLファイル」です。iPhoneで使う方法：

### 方法A：無料ホスティングで開く（おすすめ）
GitHub Pages / Netlify / Cloudflare Pages などに `index.html` `style.css` `app.js`
をそのまま置くと、URLが発行され、iPhoneのSafariで開けます（無料）。
一度「ホーム画面に追加」すればアプリのように起動できます。

### 方法B：PCでローカル確認
PCでこのフォルダに入り、簡易サーバーを起動してSafari/Chromeで開く：
```
py -m http.server 8777
```
ブラウザで `http://127.0.0.1:8777/` を開く。

> iPhoneで `index.html` をメール/ファイル経由で直接開く方法もありますが、
> ホスティング（方法A）が最も安定します。希望があればセットアップを案内します。

## きれいに消すための撮影のコツ
- **明るく・均一な光**で撮る（影を作らない）
- **ページを正面から**、できるだけ水平に撮る
- **本の綴じ目の暗い影**はノイズになりやすい → ページを大きく写し、後で必要なら切り出す
- うまく消えない写真は、しきい値スライダーで微調整する

## 技術メモ
- 手書きは印刷より薄い（実測：印刷≈濃さ100／鉛筆≈170）。影ムラ補正後、
  濃さしきい値（既定140）で分離。色ペンは彩度で判定して除去。
- PDFは外部ライブラリ不使用。各ページをJPEGとして埋め込み（DCTDecode）。
- 動作確認：Chrome で画像2枚→メモ除去→2ページPDF生成まで確認済み。
  Safari 16.4+ 相当で動作想定（最近のiPhoneはOK）。
